# O que é?
Esse é um gerador de senhas simples construido em um dia utilizando HTML, CSS e JavaScript básico. Ele pega as alternativas do usuario e pega caracteres aleatorios de uma string e adiciona a senha. Conclui esse site em 2h com pausas.
# O que aprendi?
- Verificar se um checkbox esta marcado ou não
- Pegar caacteres aleatorios de uma string usando Math.random
- Arredondar numeros usando Math.floor
- Trabalhar um pouco de flex-box
